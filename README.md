# 文言 · 上海

一个本地优先的上海高考文言文训练器样例。当前版本用于验证“短时训练 → 独立作答 → 参考答案 → 熟练度自评 → 间隔复习 → 学习记录”的最小闭环。

## 当前内容

- 6 篇教材语料样例，共 18 个训练任务
- 明确区分词句理解、翻译、信息理解、结构论证和观点表达
- 选择题自动判定；翻译题按评分点自评
- 首次练习与延迟复测分开记录
- 1、3、7、14 天的首版复习间隔规则
- IndexedDB 本地保存，浏览器不支持时回退到 localStorage
- JSON 导出与导入备份
- 响应式布局、键盘焦点、跳过链接、原生表单和 `prefers-reduced-motion` 支持

页面中的样例均标注为“内容待审核”，不代表已经核验的上海真题。正式内容接入前应完成来源、题面、答案、评分点和公开使用范围审核。

## 打开方式

直接用浏览器打开 `index.html` 即可查看静态界面。若要验证离线缓存或避免浏览器对本地文件的限制，请从当前目录启动一个静态文件服务后访问首页。
