# 文言 · 上海

一个本地优先的上海高考文言文训练器样例。当前版本用于验证“短时训练 → 独立作答 → 参考答案 → 熟练度自评 → 间隔复习 → 学习记录”的最小闭环，并将每张卡与 WB 信源库的来源层级、核验状态和使用边界绑定。

## 当前内容

- 36 篇可训练语料，共 78 个训练任务；全部标为“原创训练”，不冒充上海高考真题
- 内容由 6 篇原有教材语境、20 篇信源库文言文参照片段和 10 首信源库唐诗参照片段组成
- 每篇扩充内容附作者、篇目范围标签、教材状态和信源库文件路径；《六国论》明确标为苏辙参照版，和教材苏洵版隔离
- 明确区分词句理解、翻译、信息理解、结构论证和观点表达
- 选择题自动判定；翻译题按评分点自评
- 首次练习与延迟复测分开记录
- 1、3、7、14 天的首版复习间隔规则
- IndexedDB 本地保存，浏览器不支持时回退到 localStorage
- JSON 导出与导入备份
- “随手一张 / 三分钟练 / 读一小段 / 继续上次”四个碎片时间入口
- “按篇训练”模块：从当前 36 篇语料中抽取 5 篇，选中一篇后连续完成该篇的训练卡；可用“重置 5 篇”刷新选择
- 答案有疑问标记、跳过并延期、断点恢复
- 卡片来源字段：`sourceId`、`sourceLevel`、`sourceFile`、`verification`、`usageScope`
- 响应式布局、键盘焦点、跳过链接、原生表单和 `prefers-reduced-motion` 支持

页面中的卡片均标注为“原创训练”，依据 `E:\DEL\WB-临时\上海高考语文-信源库` 的课程标准、教材篇目、官方评析索引和文本参照层设计。原文片段按信源库参照层与通行教材常用字句整理，并经过简体化和现代标点处理以适配闪卡阅读；正式默写或考试判分仍应以学校使用的教材、点校本和公开官方材料为准。当前信源库没有完整公开真题、官方标准答案和阅卷中心内部细则，因此产品不会把这些卡片称为“真题原题”或“官方评分答案”。古籍网页材料只作为三级文本参照层；《六国论》苏辙参照版与教材苏洵版单独标注，不能混用。

`expansion-data.js` 是扩充内容层，保留与 `app.js` 分离的信源元数据和原创训练卡，便于后续逐条复核或替换。

## 打开方式

直接用浏览器打开 `index.html` 即可查看静态界面。若要验证离线缓存或避免浏览器对本地文件的限制，请从当前目录启动一个静态文件服务后访问首页。
